# Docs

WASA 43代 鳥人間電装の設計資料リポジトリです。

このリポジトリでは、電装全体の構成、インターフェース、電源、設計判断、各基板の現行仕様、試験記録を管理します。

## Directory structure

- `architecture/` — システム全体構成・各ノードの役割
- `interface/` — CANなどノード間インターフェース
- `power/` — 電源構成・保護・配電
- `decisions/` — 設計判断ログ。「なぜそう決めたか」を残す
- `specifications/` — 現在の仕様。「今どうなっているか」を残す
- `tests/` — 試験計画・結果・不具合記録

## Documentation policy

設計上の重要な決定を行った場合は、原則として次の2種類を更新します。

1. `decisions/` に判断理由・比較・決定内容を記録する
2. 関係する `specifications/` を現行仕様へ更新する

設計判断ログと現行仕様を分離することで、過去の経緯と現在の正しい仕様を混同しないようにします。
